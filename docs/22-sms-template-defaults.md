# متن پیش‌فرض پیامک‌های شعبه (فرمت ذخیره‌شده در Arte)

همان `Default` در `SmsTemplates.Branch` و `SmsTemplates."ApprovedText"`.
تگ‌ها را عین همین بنویس. سقف ۴۰۰ نویسه. پیام‌های لینک‌دار باید `{{CustomerLink}}` داشته باشند.

کد ورود (`auth.otp`) سراسری است:  
`آرته سرویس\nکد ورود: {{Code}}\nدر اختیار کسی نگذارید.`

---

## case.opened — هنگام پذیرش

```
🚗 اطلاعیه پذیرش خودرو

{{CustomerName}} عزیز،
خودروی {{Vehicle}} در {{WorkshopName}} پذیرش شد.

برای مشاهده وضعیت پذیرش و پیگیری مراحل سرویس و تعمیر، از لینک زیر استفاده کنید:

{{CustomerLink}}
```

## case.ready — آماده‌ی تحویل

```
✅ خودرو آماده تحویل است

{{CustomerName}} عزیز،
خودروی {{Vehicle}} پس از انجام خدمات موردنظر، در {{WorkshopName}} آماده تحویل است.

برای مشاهده جزئیات خدمات انجام‌شده:

{{CustomerLink}}
```

## case.delivered — هنگام تحویل

```
📋 اطلاعیه تحویل خودرو

{{CustomerName}} عزیز،
خودروی {{Vehicle}} به شما تحویل داده شد.

سوابق خدمات، جزئیات تعمیرات و اطلاعات ضمانت از طریق لینک زیر در دسترس شماست:

{{CustomerLink}}
```

## case.link — ارسال دوباره‌ی لینک

```
🚗 پیگیری وضعیت خودرو

{{CustomerName}} عزیز،
برای مشاهده آخرین وضعیت خودروی {{Vehicle}} و جزئیات خدمات ثبت‌شده در {{WorkshopName}}، از لینک زیر استفاده کنید:

{{CustomerLink}}
```

## case.waiting_part — منتظر قطعه‌ی مشتری

```
🔧 اطلاعیه وضعیت تعمیر خودرو

{{CustomerName}} عزیز،
ادامه مراحل تعمیر خودروی {{Vehicle}} در انتظار تأمین قطعه است.

پس از فراهم شدن قطعه، مراحل کار ادامه خواهد یافت.

برای مشاهده آخرین وضعیت:

{{CustomerLink}}
```

## survey.request — نظرسنجی بعد از تحویل

```
⭐ ثبت نظر درباره خدمات

{{CustomerName}} عزیز،
از انتخاب {{WorkshopName}} سپاسگزاریم.

لطفاً تجربه خود از خدمات ارائه‌شده را از طریق لینک زیر با ما به اشتراک بگذارید. نظرات شما به بهبود کیفیت خدمات کمک می‌کند.

{{CustomerLink}}
```

## staff.work_finished — به استادکار

```

خودروی {{Vehicle}} با کد پذیرش {{CaseCode}}، مراحل سرویس و تعمیر را به پایان رسانده است.

لطفاً جهت بررسی و بازبینی نهایی اقدام کنید.

{{WorkshopName}}
```
