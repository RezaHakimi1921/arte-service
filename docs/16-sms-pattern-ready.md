# 16 — الگوی پیامک «آماده‌ی تحویل» (case.ready)

برای Faraz / ایران‌پیامک این متن را در پنل سرویس‌دهنده به‌عنوان الگو ثبت و تأیید کنید. متغیرها دقیقاً همین نام‌ها هستند و در کد از همین نام‌ها پر می‌شوند:

| متغیر | معنی |
|---|---|
| `name` | نام مشتری (اگر نبود: «همکار») |
| `vehicle` | وسیله، مثلاً «موتور هوندا کلیک ۱۵۰» |
| `shop` | نام تعمیرگاه |
| `code` | کد پیگیری مشتری (برای ساخت لینک) |

**متن الگو:**

```
آرته سرویس
%name% عزیز، %vehicle% شما در %shop% آماده‌ی تحویل است.
جزئیات و هزینه: service.artepersia.com/t/%code%
```

نشانه‌ی `%` را طبق راهنمای سرویس‌دهنده‌ی خودتان (گاهی `{}`) بگذارید؛ نام متغیرها ثابت‌اند.

**نکته:** هر الگو فقط یک‌بار تأیید می‌شود. تا تأیید نشود، `Sms:IranPayamak:Templates:case_ready` (یا `IRANPAYAMAK_CASE_READY`) را خالی بگذارید؛ در این صورت این پیامک فرستاده نمی‌شود و در لاگ خطای `template_not_configured` می‌آید. کد الگو را بعد از تأیید در `deploy/.env` بگذارید و `docker compose up -d` بزنید.

متن پیش‌فرض همین پیام برای مسیر اسمارت (بدون الگو) در `src/Arte.Core/Messaging/SmsText.cs` است.
