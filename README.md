# Arte Service

سیستم مدیریت عملیات کسب‌وکارهای خدماتی، **Case-centric** و **Workflow-centric**، با رویکرد Mobile First.
بازار اول: **موتورسازی** (تعمیر موتورسیکلت).

> Arte یک پلتفرم مدیریت عملیات و رابطه با مشتری برای کسب‌وکارهای خدماتی است که Workflow هر کسب‌وکار را قابل تعریف و اجرا می‌کند.

## استک

- Backend: ASP.NET Core (.NET 10) Web API + EF Core + PostgreSQL
- Frontend: PWA موبایل‌محور، فارسی و RTL
- Multi-tenant از روز اول
